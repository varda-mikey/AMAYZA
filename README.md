# AMAYZA Support App

Standalone ID Maker and Price Tag Maker for D.A.Y. & COLE Scents and AMAYZA beverages.

## Publish

In Settings → Pages, select Deploy from a branch, main, / (root), then Save.

Employee IDs use front/back cards, photo and signature uploads, JPG download and print / PDF. Price tags support bulk product entry, editable prices, brand logos, A4 printing and JPG download. Each brand uses separate browser storage; no ChatGPT login is required. Initial product prices are examples and should be replaced.

ID layout adapted from the owner's VG-SUPPORT-APP. JPG export uses html2canvas 1.4.1 (MIT), loaded from jsDelivr.
